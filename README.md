# 🎓 Student Utility Management System

A web-based application designed to help students manage academic utilities like notes, attendance, timetable, and results.

---

## 🚀 Features
- Secure Login System
- Student Dashboard
- Attractive UI with Multiple Colors
- Background Image Design
- PHP & MySQL Backend

---

## 🛠 Technologies Used
- HTML
- CSS
- JavaScript
- PHP
- MySQL
- XAMPP
